
# F05 两直线基准面

## 输入与几何语义

`nx_prepare_datum_plane` 增加 `line1_id` 与 `line2_id`，不传外部 `mode`，也不能混入固定坐标、参考面、距离或角度字段。两个 ID 必须唯一解析到当前零件的不同原生 `NXOpen.Line`，包括已有草图线；不支持 Edge、DatumAxis 或任意坐标替代。

```json
{
  "operation_id": "f05-prepare-1",
  "ownership_id": "<current owner>",
  "binding_epoch": 1,
  "revision_id": "<current revision>",
  "line1_id": "<first current Line journal_id>",
  "line2_id": "<second current Line journal_id>"
}
```

先用 `nx_inspect_sketch` 读取草图 `geometry` 中 `kind="LINE"` 的 `journal_id`；已有 F01 工具可在指定平面创建所需草图线。NX 可在新增几何时重编号 JournalIdentifier，模型修改后须重新查询。这里仅引用既有直线，不交付 F20 空间曲线创建。

按无限直线而非有限线段判定：接受两条相交非平行线（交点可以在线段之外），或两条不同的共面平行线。明确拒绝同对象、共线重合（包括不相接的共线线段）、异面、退化及非 Line。平面的法向正负由 NX 原生确定，不作为输入方向承诺。

长度单位为毫米。退化长度阈值为 1e-6 mm；单位方向叉积范数不大于 1e-10 时按平行处理；平行线间距不大于 1e-6 mm 时拒绝共线。两条线的四个端点必须均在预期平面与实际结果平面 1e-6 mm 内。单位法向按正向或反向的逐分量误差不大于 1e-7 比较，方向无量纲。这些是 CAD 数据判定阈值，不是制造精度或测量结果。

## 原生实现与验收原则

NX2506 API 探针确认原生路径为 `DatumPlaneBuilder.GetPlane → SetMethod(TwoLines) → SetGeometry([line1,line2]) → SetAlternate(Three) → Evaluate → CommitFeature`。`Alternate.One/Two/Four` 可以生成不包含两条输入线的其他解，不能作为 F05 成功结果。准备阶段独立判定几何，不依赖 NX 接受输入即认为共面。

准备阶段的几何阈值不保证 NX 内核一定能求解。实机探针中，位于 `[100,200,300] mm` 的特定倾斜直线组合，1e-5—1e-3 mm 的短线被原生 `Evaluate` 拒绝，0.01 mm 成功；特定近重合近平行组合的单位方向差为 1e-7—1e-4 时，NX 提交了法向和端点残差错误的平面，1e-3 时正确。这些是具体输入的实测结果，不是所有零件通用的内核阈值。此类输入即使 prepare 通过，execute 仍必须通过原生求解和独立回读；失败返回真实错误并验证 Undo 恢复，不能把它们标成已创建。

以实际 `DatumPlane.Origin/Normal`、`Plane.Method/GetAlternate/GetGeometry`、两条源 Line 的身份与端点、草图源特征父关联进行回读。独立原生直线可能没有父 Feature，关联以原生 `GetGeometry()` 精确引用为依据；不能伪造父特征。

F05 的 `x_axis_source` 说明检查坐标系的来源：正常为 `datum_corner_edge`；若原生显示边框的面内边退化，则以真实 line1 方向向实际平面投影，标为 `line1_direction_projected`。这只提供回读坐标基，不替代法向和四端点的正确性检查；错误原生平面仍须回滚。F02—F04 的坐标系语义保持原样。

接口沿用 prepare → execute → 独立 verify → save/reopen，复用所有权、主线程、撤销与 UNKNOWN 停写行为。两条线的关联和几何参与 inspect、revision、执行复核及保存重开检查。新基准面可作为 F01 草图支撑。

## 验证与复现

最终 NX 验收 32/32，含 11 项成功平面、14 项 prepare 拒绝、2 项真实数值失败恢复，以及 fixture、F01 草图支撑、两源线分别更新/旧计划失效/Undo 和保存重开。两项数值失败返回已验证的 `ROLLED_BACK`，不能把它们称为成功创建。最终生产构建的 F04/F03/F01F02 回归分别 26/26、14/14、11/11，CLR/协议 105/105、独立单元 26/26。
