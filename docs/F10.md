
# F10: Project model curves into a sketch

## Objective

Project explicitly selected solid edges or model curves onto an explicitly selected native sketch, preview the result before mutation, and report the generated geometry and native source relationship. The operation must not create WAVE links.

## Request interface

`nx_prepare_sketch_projection` returns a read-only plan. `nx_edit_sketch_projection` performs preparation, execution, and verification under one `operation_id`.

Both tools require:

- `sketch_id`: the target native sketch ID from `nx_inspect_part`.
- `source_curve_ids`: 1 to 128 unique model-curve or solid-edge IDs from `nx_inspect_part`.
- `direction_xyz`: a finite nonzero world XYZ vector. The host normalizes it. The NX sketch projection API only supports projection along the target sketch normal, so F10 accepts either the parallel or antiparallel vector and rejects other directions during prepare.
- `associative`: a required boolean. `true` requests an NX associative projection; `false` requests independent sketch geometry.

The source and target must belong to the current Work Part. This scope avoids interpart links and WAVE behavior.

## Supported geometry

F10 supports model `Line` and circular `Arc` curves, plus linear and circular solid `Edge` objects. A circular source is supported only when its circle plane is parallel to the target sketch plane; a tilted circle would project to an ellipse and is rejected. A line that collapses to a point when projected is rejected in prepare. Other curve and edge types return an explicit unsupported-geometry error.

For preservation, the adapter captures complete existing `Part.Curves` definitions using the established M2 reader (Line, Arc, Ellipse, Elliptical Arc, and Spline). If any global curve definition cannot be fully read, F10 prepare rejects the part. Projection is into a native sketch in the same Work Part and creates no WAVE link.

`CurveType.Original` is used so parallel circular arcs and full circles remain native arcs. Associative mode creates an embedded NX `ProjectCurve` (`CPROJ`) operation under the sketch. Non-associative mode creates sketch geometry without a persistent source operation; results explicitly report that there is no persistent source relation. In the native probe, `UF.Sket.AskReferenceStatus` returned `Active` for output curves in both modes; F10 reports associativity from the CPROJ feature and its Section source list, not from the Sketch reference status.

## Execution and verification

Prepare validates the binding and revision, confirms no sketch is currently active, resolves the target and source IDs, captures source geometry values and model state, checks the direction against the target normal, and predicts the projected Line or Arc geometry.

Execute creates one NX undo mark, activates the requested sketch, calls `SketchProjectBuilder`, performs sketch updates while the sketch is active, deactivates it, and updates the model through NX's update manager. Verification reads back the new sketch geometry and compares its type and numeric geometry to the independent projection preview. For associative mode it edits the created CPROJ builder and compares its native section source Tags and associativity setting with the request. For non-associative mode it checks that no CPROJ operation was created and labels the output as independent geometry.

NX can add the target sketch's internal origin `Point` to `Part.Points` when the sketch is activated. F10 reads `Sketch.OriginPoint` during prepare and, on execution, permits only that exact point Tag with the same-part ownership and sketch-origin coordinates. Any other new point, axis, or direction fails preservation checks.

Failure handling uses the same undo mark to restore the model and compares the captured geometry, source values, sketch constraints and frames, reference states, bodies, history, dirty state, feature inventory, and active-sketch state. If restoration cannot be proven, the operation is `UNKNOWN` and the bridge blocks subsequent writes until the outcome is resolved. An `UNKNOWN` result is never replayed automatically.

The adapter captures every complete global `Part.Curves` geometry record before mutation, including unrelated Ellipse and Spline geometry, and rejects the prepare if any global curve type lacks a full native record. Associative CPROJ helpers are allowed only by exact Tag from that one Section and are checked against the original selected source geometry even when they are not members of `Part.Curves`. The NX builder uses a 0.001 mm projection and section tolerance. Independent geometry verification targets 1e-6 mm for points and lengths and 1e-7 rad for direction comparison. These are software verification tolerances, not NX kernel accuracy claims.

## Risks and open limits

The target sketch projection API has no custom direction input. F10 therefore limits projection to the sketch normal and rejects arbitrary oblique directions. The accepted evidence is limited to the listed same-part NX2506 millimeter matrices; trimmed circular edges, oblique projection, cross-part links, and projection that produces an ellipse are outside scope. The recorded CAD comparison tolerances do not claim manufacturing accuracy or cross-version behavior.
