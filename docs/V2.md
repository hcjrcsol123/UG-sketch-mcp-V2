# V2 功能索引与使用边界

服务版本 0.22.0 提供 42 个 MCP 工具。下面按功能说明索引；完整工具参数与当前 schema 以客户端 `tools/list` 为准。

| 功能 | 说明 |
| --- | --- |
| 空间平面与平面草图 | [F01/F02](F01-F02.md)、[距离基准面 F03](F03.md)、[角度基准面 F04](F04.md)、[两直线基准面 F05](F05.md) |
| 组合轮廓和草图编辑 | [图元 F06](F06.md)、[圆角与倒角 F07](F07.md)、[偏置 F08](F08.md)、[阵列和镜像 F09](F09.md)、[投影 F10](F10.md)、[参考状态转换 F11](F11.md) |
| 建模特征 | [拉伸 F12](F12.md)、[旋转 F13](F13.md)、[孔和螺纹孔 F14](F14.md)、[实体布尔 F15](F15.md)、[边倒圆 F16](F16.md)、[实体倒斜角 F17](F17.md)、[特征阵列 F18](F18.md)、[特征镜像 F19](F19.md) |
| 路径与扫掠 | [空间曲线 F20](F20.md)、[扫掠 F21](F21.md) |
| 其他 | [原生螺旋特征](M7-native-helical.md)、[独立 Python Journal F22](F22.md) |

F08—F22 中部分功能还提供同目录的 `Fxx-api-notes.md`，用于维护 NXOpen 接口。

常规建模在经授权的工作零件中，使用当前会话的对象标识、所有权、绑定和修订；执行后需查询及独立回读。支持的几何和组合以各功能说明为限。单位通常为毫米及角度制，具体字段以 schema 和功能文档为准。改变模型后重新 inspect；会话 Tag 和凭据不能跨会话复用。

扫掠只支持限定的截面、路径、方向及固定 DatumCsys 支撑；零件已有 `SKIN`/Swept 时旧建模及编辑写入口保守拒绝，建议先准备路径和草图。特征阵列与镜像、倒圆、倒斜角及布尔也有限定对象和几何条件。任何有限点采样和容差均不是整曲面误差界或制造精度保证。

Journal 在独立 batch 会话中运行受信任的 Python 脚本，可以产生本机文件、网络和模型副作用。它并非沙箱，观察不保证发现全部变化或撤销副作用；不支持 C#。出现 UNKNOWN 时停止写入、不重放、不自动解冻。更多内容见 [F22](F22.md)。

本项目面向 NX 2506 的记录范围；不据此声称其他版本、全部几何和跨机部署已验证。验证现状及已知测试缺口见 [testing](testing.md)。
