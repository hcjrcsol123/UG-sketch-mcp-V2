# F17 原生实体倒斜角

** 无未关闭产品阻塞。用户授权完成 F17 后停止，F18—F22 不实施。

## 目标与范围

对当前独立毫米工作零件中的显式实体直边，创建 NX 原生 Chamfer，支持等距、双距离、距离/角度三种方式。复用 prepare → execute → get → 显式 fresh verify、真实事务 Undo 和 SaveCopy/reopen。

首版限定完整世界轴对齐长方体的一条直边。必须由实际边面证明输入域，不能只依赖包围盒。旋转体、曲边、复杂交汇、多边和已倒角体上的追加不在首版范围。已有倒角的其它体应在新操作中得到保全。

## 朝向与尺寸语义

入口 `nx_prepare_chamfer`，九项共同必填：`operation_id`、`ownership_id`、`binding_epoch`、`revision_id`、`target_body_id`、`edge_ids`、`mode`、`reference_axis`、`distance_mm`。使用当前会话和修订中的显式目标及边标识，`edge_ids` 必须恰含一条边。`mode` 为 `equal_distance`、`two_distances` 或 `distance_angle`。

`reference_axis=x|y|z` 必须与所选直边的轴正交。在垂直于边的横截面内，定义 u 沿参考轴、v 沿另一横轴，两者的正向均由所选角点指向实体内部。因此在世界坐标的最大端角点处，正向可以与世界轴的正向相反。

`distance_mm=d` 为 u 方向的正截距。另一个正截距 e 按模式确定：

- 等距：e=d。
- 双距离：e=`second_distance_mm`。
- 距离/角度：e=d×tan(`angle_deg`)，角度严格介于 0° 与 90° 之间，表示截面倒角斜线与参考轴无向直线的锐角。

截面倒角边满足 u/d+v/e=1。NX 原生模式、表达式、实际选择规则及方向选项须回读，并与结果的实际截距相互核对，不将 NX 默认边顺序作为公共朝向语义。

等距不允许附带 `second_distance_mm` 或 `angle_deg`；双距离只增加必填 `second_distance_mm`；距离/角度只增加必填 `angle_deg`。全部距离必须正且有限。完整盒预检要求两个横向尺寸均大于 `2×max(d,e)+1e-6 mm`，以保证初始原生方向及交换方向都有可分离的构造余量。

本机 API 探测证明相邻面的返回顺序不能预测原生第一距离的物理方向。产品在同一外层事务中允许一次受限方向校正：首次结果通过完整请求几何则直接结束；仅当全部结果边面证明恰好为交换截距形态，且原生参数、选择关联、非目标及已有定义保全均通过时，才重开同一特征并翻转一次 `ReverseOffsets`。随后重新核对完整结果。任何其它失配回滚整个事务；资源清理不确定按 UNKNOWN 处理。这不是失败操作的重放，成功只在最终核对后发布。

共享路径影响：SaveCopy 增加既有原生 Chamfer 定义的严格保全。仅接受单边、单 `EdgeDumb` 规则、`EdgesAlongFaces` 且未启用 `AllInstances` 等受支持原生选项；已有多边、其它选择规则或其它不支持配置会保守拒绝。不能据此宣称任意含旧倒角的模型均支持保存，也不扩展旧操作对任意倒角历史的验证范围。

## 几何判据与验证

边长 L 对应的理论去除体积为 L×d×e/2；新斜面面积为 L×sqrt(d²+e²)。必须核对所有结果直边、各裁剪平面的边界和面积、双向边面邻接及原生定义；体积和包围盒本身不足以验收。全体非参与体、已有定义、表达式和依赖应按项目保全契约核对。

产品核对门限：点/距离 1e-6 mm、方向平行判定 1e-8，面面积误差不超过 max(1e-5 mm², 期望面积×1e-6)，体积误差不超过 max(1e-5 mm³, 期望体积×1e-7)。fresh 的原生定义、公开几何与完整体指纹仍按执行后严格比较，不继承 F13 的特定 UV 舍入例外。

验证仅覆盖限定夹具与方向，旋转体、复杂几何、非空旧 Hole/Boolean/Revolve/Blend 混合、运行中断连、失败 Undo、其他 NX 版本及数值极限尚未覆盖。一次 prepare 前后快照比较失败时未记录完整 after 明细，原因未明，后续可观测检查不能证明差异已消失。UNKNOWN 不重放、不自动解冻；数字模型核对门限不构成制造精度声明。
