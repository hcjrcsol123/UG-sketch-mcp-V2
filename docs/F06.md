
# F06 原生草图组合轮廓

## 输入

沿用所有权、`binding_epoch`、`revision_id` 和 prepare → execute → verify → save/reopen 生命周期。`geometries` 最多 32 条记录，各记录必须有不同的 `id`，二维坐标相对于草图局部坐标系，长度为毫米，输入角度为度。`start_angle_deg` 与 `rotation_deg` 范围为 `[0,360)`，负旋转可输入等价正角度；只有 `sweep_deg` 使用带符号角度。

草图顶层可选 `constraint_mode`：省略或 `legacy_driving` 保留原有线段／矩形／整圆的尺寸约束行为；`geometry_only` 只创建原生几何，不自动增加驱动尺寸或推断约束。凹形、内环、多区域及其他组合轮廓应显式使用 `geometry_only`。旧逐图元绝对位置／长度标注策略可能使合法闭环过约束，不能把过约束状态当作成功，也不能静默改模式后重放。

| type | 必需几何字段 | 语义 |
| --- | --- | --- |
| `arc` | `center_mm`, `radius_mm`, `start_angle_deg`, `sweep_deg` | 从局部 +X 起算，正扫角为逆时针，允许负扫角；`0 < abs(sweep_deg) < 360`。完整圆使用已有 `circle`。 |
| `ellipse` | `center_mm`, `major_radius_mm`, `minor_radius_mm`, `rotation_deg` | 完整椭圆；长半轴不小于短半轴，均为正；主轴相对局部 +X 逆时针旋转。 |
| `elliptical_arc` | 椭圆字段及 `start_angle_deg`, `sweep_deg` | 角度为椭圆参数角；有符号扫角，绝对值小于 360 度且非零。 |
| `spline` | `interpolation_points_mm`, `degree: 3`, `endpoint_condition: "unconstrained"` | 4—32 个二维插值点，非周期三次样条；按累计弦长归一化参数；端点斜率和曲率均不施加约束，由 NX 计算。 |

样条必须明确以上端点条件；本阶段不提供控制点／阶次／节点输入，也不提供周期样条。闭合样条组合轮廓由显式端点相接的其他曲线闭合，不靠重复首尾插值点隐式生成周期曲线。

`unconstrained` 表示用户不指定切向或曲率。创建时各点输入 UF 的 `SLOPE_NONE=-1`、`CRVATR_NONE=-1`；NX2506 可在保存的原生定义中把首尾斜率记录为自动计算的 `SLOPE_AUTO=0`。原生条件码和派生向量应如实回读，不能把它们替换成请求中的 `-1`，也不能把 AUTO 当作用户指定的向量约束。

例如半圆和线段组成的闭环（其他会话字段省略）：

```json
{
  "plane": "XY",
  "origin_mm": [0, 0, 0],
  "constraint_mode": "geometry_only",
  "geometries": [
    {"id": "arc", "type": "arc", "center_mm": [0, 0], "radius_mm": 5, "start_angle_deg": 0, "sweep_deg": 180},
    {"id": "base", "type": "line", "start_mm": [-5, 0], "end_mm": [5, 0]}
  ]
}
```

同一列表可组合非矩形、凹轮廓、内环和多个独立轮廓，不自动修剪相交曲线或猜测用户意图。空草图与开放曲线仍受支持，但不能作为有效闭合区域报告。

## 原生回读与轮廓状态

创建使用 NX 原生曲线和 `Sketch.AddGeometry`；椭圆旋转只改变轴向，不旋转其输入中心。样条使用 `UF.Curve.CreateSplineThruPts`，保存原生定义，供独立回读。

本机 NX2506 的椭圆构造器采用极角，UF 曲线求值采用椭圆参数角，两者必须显式转换。F06 的椭圆弧输入仍采用参数角；真实端点和内部点以原生求值核对。

默认模式下，原有线段、矩形、整圆仍保留既有尺寸约束；新增曲线按指定几何创建，不自动补充尺寸、相切或固定约束。`geometry_only` 下全部图元都不自动加约束，矩形仍由四条原生直线构成。草图可以保持欠约束，`VALID_CLOSED_PROFILES` 只表示几何轮廓状态，约束状态由草图检查单独返回；此模式没有自动生成的 Driving 尺寸供既有尺寸编辑工具使用。

`nx_inspect_sketch` 的 `geometry` 回读世界坐标与原生对象类型。椭圆提供 `major_radius_mm`、`minor_radius_mm`、`major_axis_direction`、`normal`、参数起止角和世界端点；样条提供原生次数、周期性、插值点、参数及端点。新增几何也参与修订跟踪、独立 verify 和保存重开检查，不能只回显输入。

执行和验证结果的 `profile_analysis` 区分 `EMPTY`、`OPEN_GEOMETRY`、`VALID_CLOSED_PROFILES` 及明确错误／分析不可用状态。依据为原生有限曲线求交、样条自交检查、真实端点连通性和 NX Section 分类；Section 的“成功”或 loop count 本身不能证明轮廓有效。原生求交对重合曲线可能返回零交点，仍须检查重叠。原生错误和无效轮廓复用现有 Undo 恢复与 UNKNOWN 停写行为。

本机探针还确认，创建并销毁 Section 会把干净零件标记为 modified。因此 prepare、inspect 与 revision 不能为分析创建 Section。执行时的 Section 分类与 verify 中独立检查的具体实现及容差，以最终接手记录和源码为准。

`VALID_CLOSED_PROFILES` 是当前零件／NX2506 的 CAD 几何结论，不是制造精度、全面跨版本支持或任意轮廓拉伸已交付的声明。

## 复现

生产构建：`tools/build-m2-bridge.ps1`；真实 NX 验收：`tests/nx/v2/build-f06-acceptance.ps1` 后运行 `RunF06Acceptance.py`。开发 Journal 只用于验收，不构成 F22 产品工具。

安装版代表性调用见 `tests/nx/v2/smoke-f06-mcp.py`；独立新模型由 `tools/v2/create-f06-mcp-fixture.py` 创建。生产 DLL 替换前须正常保存退出对应 NX，不热替换。
