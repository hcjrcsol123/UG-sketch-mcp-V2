## 目标与验收边界

在显式草图中，以当前查询所得源曲线标识，创建 NX 原生直线、矩形、圆周阵列，或按该草图内指定直线镜像。保留源几何、既有约束及其参考状态；检查非目标草图、框架、历史、表达式和实体。长度为毫米，角度为度，方向和圆心为草图局部二维坐标。

采用 `nx_prepare_sketch_pattern` 只读预览和 `nx_edit_sketch_pattern` 单操作 prepare → execute → verify；保留通用 execute/verify 入口。沿用所有权、修订、NX 主线程队列、操作查询、Undo 与 UNKNOWN 停写语义。不得自动重放未知结果。

接口约定（具体 schema 与实现限制以本页及 capabilities 为准）：

| mode | 参数与含义 |
| --- | --- |
| linear | `direction_xy`、正 `spacing_mm`、`instance_count`；总位置数包含源位置，方向归一化。 |
| rectangular | 正交 `direction_x_xy` / `direction_y_xy`、正 `spacing_x_mm` / `spacing_y_mm`、`count_x` / `count_y`；总位置数为两计数乘积，包含源位置。 |
| circular | `center_xy`、有符号 `angle_step_deg`、`instance_count`；`0 < abs(angle_step_deg) < 360`，第 i 个位置绕草图法向旋转 i × 步角，i=0 为源。 |
| mirror | `axis_curve_id` 为目标草图内的显式原生直线，不能同时作为源曲线。 |

共有目标字段为 `sketch_id`、非空且唯一的 `source_curve_ids`，以及既有 operation/ownership/binding/revision 字段。支持原生 Line、部分圆弧 Arc 和整圆 Arc；Ellipse 与 Spline 不支持，并在只读预览阶段拒绝。

阵列总位置数限制为 2—256（矩形两个方向均至少 2），源曲线至多 256 条；总位置数 × 源曲线数不得超过 4096。新增输出数为 `(总位置数 − 1) × 源曲线数`；镜像为每条源新增一条。源位置和新增实例之间的重合须显式处理，不可把缺失或复用输出当作正确数量。

例如，调用 `nx_edit_sketch_pattern` 时传入以下参数，沿归一化后的 `[3,4]` 方向按 5 mm 间距生成含源的三个位置，每条源新增两条曲线。示例标识必须替换为当前会话实际返回值，新的编辑使用新的 operation_id：

```json
{
  "operation_id": "f09-linear-example-01",
  "ownership_id": "<current ownership_id>",
  "binding_epoch": 1,
  "revision_id": "<current revision_id>",
  "sketch_id": "<current sketch journal_id>",
  "source_curve_ids": ["<current curve journal_id>"],
  "mode": "linear",
  "direction_xy": [3, 4],
  "spacing_mm": 5,
  "instance_count": 3
}
```

预览包含实际源记录、`expected_pattern_instance_count`、`expected_output_curve_count` 和 `expected_instances`；后者只是请求变换后的预期。成功结果必须通过实际输出的一对一匹配和九项后验：`pattern_instances`、`source_curves`、`sketch_constraints`、`sketch_frames`、`reference_status`、`non_target_geometry`、`history`、`bodies`、`sketch_solver_status`。`pattern_instances` 还检查辅助对象库存恢复。修改后重新查询对象 ID；原生 Tag 用于一次事务内保持身份，旧 JournalIdentifier 可能重编号，不能跨编辑当作稳定身份。

## 数值判据与原生策略

局部点 p 的预期变换独立于 Builder 输出计算：直线为 `p + i·s·d̂`；矩形为 `p + i·sx·x̂ + j·sy·ŷ`；圆周为 `c + R(i·θ)·(p−c)`；镜像为 `a + 2·d̂·[d̂·(p−a)] − (p−a)`。世界坐标由草图原点和正交面内轴映射。预览只计算预期，不把它作为原生实际输出证据。

实现策略为**独立几何阵列**：linear / rectangular / circular 对源 Line、Arc 的原生定义做刚体变换，再通过 `NXOpen.CurveCollection.CreateLine` / `CreateArc` 和 `Sketch.AddGeometry(InferNoConstraints)` 创建原生草图图元；圆周旋转采用世界坐标 Rodrigues 公式，同时变换 Arc 圆心和源原生面内基向量，保留半径与有效单圈参数域。`native_engine` 如实标记为 `NXOpen.CurveCollection geometry pattern`。

镜像继续使用 `SketchMirrorPatternBuilder`，不得将源或轴转为参考。该接口 `Commit()` 返回空值本身不代表失败。各模式输出均通过 `Sketch.GetAllGeometry()` 的原生 Tag 差识别；每个预期实例与一条实际输出唯一匹配，并核对源和非目标的数值基线。圆弧须核对中心、半径、端点、绝对扫角/长度及内点，镜像需处理方向反转，整圆不依赖任意起始参数。

专用 `SketchPatternBuilder` 探针中的零输出和回读停滞是历史调查记录，未证明全部 Builder 配置失败。F09 独立几何阵列已通过本机原生验收和 installed MCP 实测验收；探针没有证明 NX 内核存在缺陷。

沿用既有 NX 读取契约：部分 NXOpen getter 可将零件标记为 modified，`InspectPart` / `GetSession` 的 `read_effects` 如实报告，不强行清 dirty。验收先保存独立夹具，再显式读取并记录该副作用，随后以真实读取后的状态建立严格基线；不得在读取后再次保存为 clean 并将下一次相同读取误判为建模修改。预览不创建曲线、约束或特征；实际失败 Undo 的 dirty/activeSketch 恢复仍必须与执行前真实状态相符。
