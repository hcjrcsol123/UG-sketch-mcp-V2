# F18 原生特征阵列

## 目标与使用边界

`nx_prepare_feature_pattern` 为一个明确的 `seed_feature_id` 准备原生特征阵列计划；prepare 不承诺已建模。按当前会话的 `ownership_id`、`binding_epoch`、`revision_id` 提交，审查返回计划后用 `nx_execute_plan` 执行，再以 `nx_verify_part` fresh 核验。能力状态分别由 `model_feature_pattern_adapter_available` 和 `model_feature_pattern_write_enabled` 报告。一次执行结果不等于完整项目接受。

| 模式 | 相对于种子的预期变换 |
| --- | --- |
| `linear` | 第 `i` 个为 `i * pitch1_mm * direction1` 平移。 |
| `rectangular` | 第 `(i,j)` 个为 `i * pitch1_mm * direction1 + j * pitch2_mm * direction2` 平移。 |
| `circular` | 绕过 `axis_origin_mm`、沿 `axis_direction` 的世界坐标轴，按右手规则旋转 `i * angle_deg`；角度可正可负。 |

下标从零开始，数量包含原种子。每个有效方向的计数为 2–32，矩形 `count1 * count2 <= 32`；间距为正有限数，坐标与长度单位 mm、角度单位度。方向向量为三个有限数字，长度与 1 的误差不超过 `1e-9`；矩形两方向点积的绝对值不超过 `1e-9`。圆周轴点为三个有限数字，角步长必须有限且非零，并满足 `(count1 - 1) * abs(angle_deg) < 360`。模式字段互斥，拒绝多余字段。完整字段见 [接口说明](F18-api-notes.md)。

当前设计范围是同一活动零件内、独立且完整的世界轴对齐长方体：一个原生 `BLOCK` 或 `EXTRUDE` Create 特征，拥有一个实体且没有下游修改。要求实例与其他实体的变换后轴对齐包围盒具有正间隙；包围盒保守筛选可能拒绝实际不接触的旋转实体。变换坐标超出保守绝对值 `1e8 mm` 的几何范围时，prepare 局部拒绝；这不是请求字段的有限数校验上限。复杂或已修改实体、接触或不能证明分离的情况不在当前支持域。数量与几何容差是实现条件，不是制造精度声明。

产品原生与安装样例使用 `EXTRUDE` 种子和负圆周步角；`BLOCK` 种子及正步角有 API 探索记录，未单独作为产品建模案例验收。非世界轴圆周和一般斜向阵列也未作产品实测。

准备、提交或读回产生未知状态时停止后续写入，不自动重放或解冻。Tag 仅用于当前 NX 会话；保存后应根据几何与原生关联重新识别，不能跨会话比较 Tag。盒体的完全对称姿态可能产生相同几何，须同时依赖原生方向和关联证据。

## 验证边界

产品种子实测为 EXTRUDE，BLOCK sentinel 不构成 BLOCK 种子建模证据。产品验收没有覆盖其他 NX 版本、一般轴向、正圆周步角、复杂混合特征、种子编辑后的传播、真实丢响应或失败 Undo，也不证明可靠性、制造精度或标准符合性。
