# F16 恒定半径边倒圆

## 目标与接口

在当前独立毫米工作零件内，对显式单实体的指定边集合创建 NX 原生恒定半径 EdgeBlend 特征。复用 prepare → execute → get → 显式 fresh verify、事务 Undo 和 SaveCopy/reopen。

`nx_prepare_edge_blend` 七项全必填：`operation_id`、`ownership_id`、`binding_epoch`、`revision_id`、`target_body_id`、`edge_ids`、`radius_mm`。目标为 single solid；数组允许 1—32 条唯一边，全部属于目标；半径为正有限毫米值。使用当前查询的对象标识，修改后重新查询，不默选目标或边。

首版限定：世界轴对齐、六平面/十二直边/八顶点的完整长方体，选择不共享端点且平行的外凸直边，倒圆邻域须可分离。两个横向尺寸均须满足 `dimension > 2 × radius_mm + 1e-6 mm`。协议数组上限不代表长方体可选 32 条有效边（平行棱最多四条）。其它几何在 prepare 或无法证明后验时明确拒绝并保持/恢复原模型。不只用包围盒判定长方体，不将该域描述为通用边倒圆。

已倒圆的体不再满足完整长方体输入域，不能对同一体逐次追加倒圆；应一次提供支持的边集合。已证明在另一未修改的长方体上继续倒圆可保全先前倒圆定义。正式实测为沿 Z 的单边和对角双边、r=2 mm，未实测 X/Y 轴、三/四边或尺寸极限，不把接口域当穷举证据。

不能把可变半径、自动相切传播、任意复杂边交汇或未实测 NX 版本列为已支持。边标识仅当前会话/修订有效，歧义不得默选。几何检验门限不代表制造精度。

共享路径影响：SaveCopy 的定义保全新增对已有原生 EdgeBlend 的检查。若零件含不支持的可变半径、非圆截面、多链集或不支持选项的旧倒圆，会显式 `UNSUPPORTED_EDGE_BLEND_PRESERVATION` 拒绝保存副本；不忽略这些定义后宣称保存验证通过。

## 实现与几何判据

新建和重开 `EdgeBlendBuilder`，严格回读一个 Circular chainset、毫米半径表达式、空 variable-radius 数组，逐项核对 `EdgeDumbRule.GetData` 与 collector、准备阶段历史输入 Tag。原输入边提交后 suppressed，不能重新取端点；准备阶段几何与原生历史关联共同证明选择。返回真实 `feature_id`、`body_ids/bodies`、`native_definition`、`coverage` 和 `result_geometry`。

输出按原长方体与所选角构建解析参考：每条恒半径圆柱的轴位置、完整长度和面积；两切线、两四分之一圆弧的中心/半径/跨度/象限；所有结果边、六平面裁剪边界、面积及双向邻接逐一匹配。另核对实体数、理论体积、全部非参与体完整指纹、原有特征/表达式/依赖/关联、旧孔/布尔/倒圆定义。新特征须有真实目标所有者父关联和 FEATURE_PARENT 依赖。

对长度 L 的一条直角外凸棱，去除体积为 `L × r² × (1−π/4)`。正式 20×12×10 mm 夹具的单边为 2391.415926535898 mm³，双边为 2382.831853071796 mm³；材料点另检查角部去除和内部保持。

产品数值门限：点/长度/半径 1e-6 mm；方向对齐 1e-8、圆弧跨度 1e-8 rad；面积 `max(1e-5 mm², expected × 1e-6)`，体积 `max(1e-5 mm³, expected × 1e-7)`。独立夹具 oracle 体积要求 1e-5 mm³。这些是数字模型核对门限，不是制造公差或质量认证。fresh 的执行后完整几何/指纹比较仍严格，不继承 F13 的特定 UV 舍入例外。

未实测任意复杂拓扑、旋转姿态、非空旧 Hole/Boolean/Revolve 混合夹具、NX 其他版本、运行中断连或失败 Undo。UNKNOWN 不重放、不自动解冻。
