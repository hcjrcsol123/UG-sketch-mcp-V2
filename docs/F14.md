
# F14 孔与螺纹孔

## 目标与约束

在本机 NX2506、独立毫米零件中，通过显式目标实体、世界坐标位置和方向创建原生普通孔、沉孔、沉头孔以及标准螺纹孔。支持盲孔和原生贯穿限界；尺寸、孔深和螺纹参数的准确语义以原生 API 探针及持久读回为依据。

执行后须从实际孔壁、端环、台阶/锥面与钻尖核对完整尺寸和材料覆盖；不能仅凭名义深度或目标体积减少判定。斜入平面、交叉孔/空腔或复杂裁剪而无法证明完整孔壁的情况保守拒绝。该边界不承诺任意曲面入孔或制造中的完整牙型/加工精度。

螺纹孔必须明确标准、规格、螺距、旋向和螺纹深度，并验证所选本机标准库记录及 NX 实际保存的定义。默认交付原生标准孔及螺纹参数/符号表示，不声称生成实体螺旋牙型。螺距不能仅因输入或标注存在就视为原生验证通过。

螺纹还必须显式提供 `radial_engage`，按有效 NX 标准库的标准/规格/啮合率唯一匹配；长度接口为 mm，角度接口为 deg。底孔尺寸由所选记录和原生回读共同核对。

保持 prepare → execute/get → 显式 fresh verify 的协议及所有权、修订、幂等、Undo 和 UNKNOWN 停写机制。非目标实体、既有草图、特征及依赖保持既有严格保护；任何新增 helper 或依赖须证明归属。

只有 root 串行启动和操作 NX。

## 职责和验收

- technical-lead/root：范围、接口裁决、唯一 NX 操作者、安装、最终验收及交接。
- systems-integration：生产代码、公共协议、原生适配与构建，记录 API 事实。
- test-validation：F14 API 探针、解析 oracle、原生及安装测试、定向软件测试。

F01—F13 已接受且无关的验证沿用，不重跑。失败后只重测修正影响范围；完整最终运行仅在集成证据需要时进行。API 探针、软件检查、原生案例、安装案例和独立断言分别记录，不能累加冒充案例数量。

若实机或标准库不支持某项，必须记录事实并解决范围问题，不隐瞒或将未验收标为完成。

## 接口

`nx_prepare_hole` → `nx_execute_plan` / `nx_get_operation` → 显式 `nx_verify_part`。prepare 需要 `operation_id`、`ownership_id`、`binding_epoch`、`revision_id`，以及以下业务字段；各变体不接受其它变体的多余字段。

| 适用范围 | 必填参数 |
| --- | --- |
| 所有孔 | `target_body_id`（当前唯一 solid）、`position_mm`（world XYZ）、`direction`（world 非零向量，归一化）、`kind`、`depth_mode` |
| `kind=simple` | `diameter_mm` |
| `kind=counterbore` | `diameter_mm`、更大的 `counterbore_diameter_mm`、`counterbore_depth_mm` |
| `kind=countersink` | `diameter_mm`、更大的 `countersink_diameter_mm`、`countersink_angle_deg`（夹角，0—180°开区间） |
| `kind=threaded` | `thread_standard`、`thread_size`、`radial_engage`、`pitch_mm`、`hand=right\|left`、`thread_depth_mm` |
| `depth_mode=blind` | `hole_depth_mm`（入口到圆柱底，另有固定118°钻尖） |
| `depth_mode=through` | 不允许 `hole_depth_mm`，使用原生 ThroughBody；实际有效壁长从 BRep 核对 |

所有数值有限；坐标绝对值及正长度上界 1,000,000 mm。沉孔深度或沉头锥段深度须小于盲孔深度；螺纹名义深度不得超过盲孔深度，并由实际孔壁覆盖检查进一步约束。英制标准同样使用 mm 接口，必须用 NX 显式长度单位赋值，不能把裸字符串数值交给标准库单位解释。

返回包含实际 `feature_id`、完整 `body_ids/bodies`、原生孔定义、材料覆盖与模型保全证据。线程明确返回 symbolic / `physical_thread_geometry=false`；标准、规格、pitch、旋向、深度、底孔、孔壁和起始平面来自原生 HolePackage/Thread 回读，而非只回显请求。几何、已有孔参数及符号圆弧在后续操作和保存重开中分别核对。

编辑后重新查询当前 JID；同一会话/修订可用 Tag 核对身份，不能跨加载复用 Tag。原生符号圆弧的 JID 会重排。保存重开采用无 Tag 的几何及持久参数关联，歧义或无法证明时保守拒绝。

## 已知支持边界

- 本机 NX2506、毫米独立零件、单显式 solid 目标；不引入装配、WAVE 或 Teamcenter。
- 单张解析面构成每个完整壁段；拆分面、交叉孔、内腔或不完整端环不能通过时拒绝。通过孔还要求目标的全部材料不超过已证出口平面；这是保守限制，可能拒绝与孔轴不相交的远处凸出部分。
- 原生建模 tolerance 0.001 mm，Section distance/chaining/angle 为 0.01 mm / 0.0095 mm / 0.5°。入口内外见证偏移 0.01 mm。
- coverage 线性门限 0.002 mm、面积绝对 1e-5 mm² / 相对 2e-6，半径至少 0.05 mm，有效壁长大于 0.1 mm。完整 fresh 体指纹和公开几何保持精确比较，没有继承 F13 的局部 UV 舍入例外。这些数值不代表制造精度。
- UNKNOWN 不重放、不自动解冻；只有已证明完整 Undo 的回滚才报告恢复成功，并推进修订。保存不以 getter 后补存伪造 clean。

## 已确认的 API 事实与交接

- Section 唯一 CurveDumb 选取的输入 Point 与原生输出 Point 不同 Tag；分别核对源身份、规则映射及双坐标。
- 内部孔与Thread的ContainerFeature可为null；按internal、timestamp、目标体/父孔、实际共享表达式及唯一使用者联合证明归属，不用JID前缀。
- 原生标准螺纹的pitch/旋向/深度、目标圆柱面与起始Plane实际回读。有效标准目录由NX Session读取；Metric Coarse M5×0.8与Inch UNC 1/4-20的记录组合已经验证，不宣称穷举标准库。
- 原生创建、fresh、真实Undo与材料拒绝、旧孔非几何定义保全、SaveCopy/reopen及installed调用均有分层证据。
