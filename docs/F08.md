
# F08 草图偏置

## 目标、范围与接口

在显式目标草图内，按有序、有向曲线链创建一次原生偏置，指定正距离（毫米）、左/右侧及角部连接方式。保留原曲线及其既有定义/约束，不转换为参考、不自动添加偏置约束或尺寸。源链、非目标几何、其他草图、特征及实体须保持。

`nx_prepare_sketch_offset` 用于只读预览，沿用 `nx_execute_plan` / `nx_verify_part`。`nx_edit_sketch_offset` 在一个可查询操作内完成 prepare → execute → 独立 verify。复用当前所有权、修订、主线程队列、撤销和 UNKNOWN 停写机制。

共同请求含 `operation_id`、`ownership_id`、`binding_epoch`、`revision_id`、`sketch_id`，以及：

| 字段 | 定义 |
| --- | --- |
| `curve_chain` | 有序数组，每项为当前草图 `curve_id` 和 `direction="forward"/"reverse"`。forward 沿原生参数增加方向，reverse 相反。相邻项实际端点须连续。 |
| `distance_mm` | 有限正毫米距离；不通过负号隐式翻转侧向。 |
| `side` | `left` 或 `right`。left 沿草图法向 × 链遍历单位切向，right 反向；反转整条链后左/右交换。 |
| `join_mode` | `extension` 或 `arc`；映射 NX 原生 SketchOffset.CapType。最终支持组合以实际几何回读证据为准。 |

不是任意轮廓拉伸或独立空间曲线功能。源对象 ID 来自当前目标草图检查，执行修改后重查，不复用历史 JID 或所有权凭据。

## 验证与边界

原生验收覆盖开放链双侧/反向、闭合轮廓内外、线弧/整圆、倾斜草图、非空约束与非目标、错误对象/参数、退化输出实际 Undo、旧计划及保存重开。数值比较为 CAD 门限，位置/长度主要 1e-6 mm，方向主要 1e-7 rad。

源曲线始终保留为原状态，输出为active普通草图几何；不建立关联偏置约束。所有草图几何、约束、框架、reference、已有实体、特征/表达式历史参与保持检查；非Sketch自由空间曲线只有原有ID级快照，未独立数值验证。

最终模型为相应run_id的`-roundtrip.prt`。
