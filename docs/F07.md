
# F07 草图圆角与倒斜角

## 需求与接口边界

- 在当前明确选择的原生草图上修改两条指定曲线；显式选择每条曲线的连接端，不猜测同类对象或角点。
- 圆角给定正毫米半径；倒斜角给定两条曲线上的毫米距离，或明确的毫米距离与度数角。必须记录角的参考曲线及方向。
- 创建后独立回读实际几何，检查修剪端点、连接性、尺寸和草图归属，以及未选中曲线保持情况。不能只回显参数或以无异常代替几何验收。
- 复用模型所有权、修订、主线程队列、prepare/execute/verify、Undo 恢复和 UNKNOWN 停写。既有曲线编辑进入修订及保存重开检查。

## 验证原则

应用与桥接集成由 systems-integration 负责；test-validation 维护独立数值与生命周期测试，主 AI 负责范围和接受。软件、探针、生产实机和安装调用分层记录，不互代。既有评审结论见验收基线；后续修改仍应检查不同连接端、倾斜草图、原曲线定义/约束与非目标、只读拒绝、真实失败恢复、旧计划及保存重开。

`nx_prepare_sketch_corner` 返回预览计划，随后沿用 `nx_execute_plan` / `nx_verify_part`。`nx_edit_sketch_corner` 在同一个可查询的操作中执行 prepare → execute → 独立 verify；重复请求及超时沿用现有操作生命周期。

两个工具共同必填 `operation_id`、`ownership_id`、`binding_epoch`、`revision_id`、`sketch_id`、`kind`、`curve1_id`、`curve2_id`、`curve1_end`、`curve2_end`。曲线与草图 ID 来自当前查询，端点为原生曲线的 `start` / `end`。

| kind | 额外必填字段 | 参数含义 |
| --- | --- | --- |
| `fillet` | `radius_mm` | 正毫米半径。 |
| `chamfer` | `distance1_mm` 及 `distance2_mm` | 从原角点分别沿两条直线量取的正毫米距离；两值相等即等距倒角。 |
| `chamfer` | `distance1_mm` 及 `angle_deg` | 第一边的正毫米距离，以及第一修剪点处的度数角；不可同时传第二距离。 |

倒角设原角点为 C，第一、第二修剪点为 A、B；`angle_deg` 是 A 处 `A→C` 与 `A→B` 的夹角 δ。两条保留射线的内角为 θ 时，`0 < δ < 180°−θ`，第二距离 `d₂=d₁ sinδ / sin(θ+δ)`。以 C=(20,0)、第一保留远端=(0,0)、第二保留远端=(20,10)、d₁=4 mm、δ=30° 为例，A=(16,0)、B≈(20,2.3094010768) mm。距离/角度请求在修改前由该公式计算第二距离，再调用 NX 原生 Asymmetric 双距离 Builder；HelpPoint 使用与尺寸大小关系无关的内角定位点 `C+ε(r₁+2r₂)`，`ε=0.1 min(d₁,d₂)`，r₁/r₂ 为从原角点指向保留远端的单位射线，之后独立回读两个修剪距离和 A 处实际角。结果必须如实区分 requested_definition=distance_angle 与 native_chamfer_mode=Asymmetric，不声明使用原生 OffsetAndAngle 角度参数。

曲线ID须从所选Sketch的当前检查结果取得；sketch_id与curve_id共同限定对象，修改后重查，不能依赖旧JID或把别的草图同值ID当作跨域身份。

NX2506 随附 NXOpen.xml 明确 `SketchChamferBuilder.CurvesToChamfer` 为两条 Line，因此倒角仅支持 Line–Line。`Sketch.Fillet` 接受 Curve，但最终支持组合以实际运行证据为准。原生文档注明镜像约束可能使额外曲线一起圆角；这类目标须拒绝，避免修改用户未选择的对象。不得静默删除既有约束。

生产build6零警告；协议/CLR148/148、独立单元31/31、F07真实NX10/10、旧F01—F06回归96/96；安装版6/6、三次建模APPLIED且独立verified，保存重开四组VERIFIED并安全交回。

不自动添加半径/倒角Driving尺寸，也不删改既有约束。若NX修剪会转移原尺寸操作数、改变原线/弧、移动远端或非目标，产品回滚并核对原状态；不能证明恢复则UNKNOWN停写。实测Driving冲突完整恢复，版本允许23→25而不倒退。

请求最小示例（身份/对象字段须替换为当前真实值）：

```json
{"operation_id":"new-unique-id","ownership_id":"current-owner","binding_epoch":1,"revision_id":"current-revision","sketch_id":"current-sketch","kind":"fillet","curve1_id":"current-line-1","curve1_end":"end","curve2_id":"current-line-2","curve2_end":"start","radius_mm":2}
```

传给nx_edit_sketch_corner即可单次执行/验证；预览则nx_prepare_sketch_corner，再使用返回plan_id沿旧execute/verify路径。倒角kind=chamfer，替换radius_mm为distance1_mm及distance2_mm或angle_deg，两者恰一。

F07不声明整体轮廓有效，不自动开放F12拉伸或F22任意Journal；偏置为独立F08功能。位置/长度主要比较1e-6 mm、角和方向另有原生数值门限，非制造精度。NX读取可能标记modified，应读取真实read_effects，不强行清标志。M7组合probe未进入F07阶段，不计为组合验证。
