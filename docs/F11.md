
# F11：转换为参考／转换自引用

## 目标与要求

在本机 NX2506、独立毫米 Work Part 内，对显式选中的草图曲线和尺寸执行原生 Reference ↔ Active 转换，提供只读 prepare 和带 operation_id 的单命令 edit。长度单位为毫米，方向无量纲；不改变所选几何的空间定义，不自动解除投影关联。

## 原生命令映射

`libsketint_simpl_chinese_nlm.txt` 第 81 行将 `Convert to Reference` 翻译为“转换为参考”。这些资源随本机 NX2506 安装提供；未从外网下载。

原生入口为 `SketchCollection.CreateConvertToFromReferenceBuilder()`，`OutputState` 使用 `OutputType.Reference` 或 `OutputType.Active`。输入必须属于活动草图；曲线直接传入，尺寸通过选中 dimensional constraint 的 `AssociatedDimension` 传入。显式设置 `SelectAllProjectFeatureCurves=false`，避免隐式扩选同一投影的其它曲线。

参考状态与投影关联是两个独立概念。恢复活动状态不应创建替代曲线，不应删除原生 CPROJ 来源关系。参考曲线仍可用于草图约束；参考尺寸不驱动几何。轮廓是否使用参考曲线还取决于下游 Section 的选择设置，F11 的原生验收明确使用 `SetAllowRefCrvs(false)`，不声称所有下游选择模式都排除参考曲线。

## 公共接口

新增 `nx_prepare_sketch_reference_conversion` 和 `nx_edit_sketch_reference_conversion`。功能字段为 `sketch_id`、`object_ids` 和 `target_state: "reference" | "active"`；其余所有权、修订和 operation 字段沿用现有协议。曲线与尺寸均使用 `nx_inspect_sketch` 当前返回的 JournalIdentifier，尺寸选约束 ID，不能传注释 ID。编辑后重新查询 ID；事务内部按 Tag 保全，跨加载不假设 Tag 持久。

允许一个请求包含曲线与尺寸，以及部分已经处于目标状态的对象；只有需要变化的项传入 builder。全部已处于目标态时在 prepare 明确拒绝，不创建编辑事务。

尺寸首轮限定 `HorizontalDim` 与 `VerticalDim` 的毫米长度。其它类型事前明确拒绝，不能因 API 接受一般尺寸就声称角度、半径／直径等单位与比例已验证。参考尺寸旧表达式可能不同于当前测量值；恢复 Active 时原生会把该尺寸自身的数值 RHS/Value 更新为当前测量，属于精确允许的变化，不允许放宽其它表达式或尺寸关联。

既有非目标 Ellipse/Spline 不需转换，但仍须完整保全，不能只比较曲线长度。尺寸表达式要求可核对的有限数值 RHS 与唯一约束关联，不将公式、共享表达式或其它尺寸族默认为已支持。

尺寸转为 Reference 时，NX 会把该尺寸表达式从目标 Sketch feature 的 `GetExpressions()` 和对应 `FEATURE_EXPRESSION` 依赖中移除；表达式对象仍可留在 Part.Expressions 并与尺寸关联。恢复 Active 时允许相应驱动关系恢复。后验只允许实际转换的所选尺寸表达式与指定目标草图特征这一对 membership 改变，并核对实际目标状态；其它表达式、其它特征及依赖边（含重复计数）须保持。不能把这一必要尺寸行为误称为解除投影来源关系。

执行事务内明确把目标求解工作区域规范化为 EntireSketch，再评估求解状态；返回时没有活动草图。失败恢复严格核对捕获的模型状态，但不保证恢复此前的非活动草图局部工作区域 UI 偏好。新建 WorkRegionBuilder 的默认 Scope 不能独立观察这一历史偏好，因此证据须将其标为 `NOT_INDEPENDENTLY_OBSERVABLE`，不能宣称所有 UI 状态都已恢复。

Prepare 可记录尚未评估的缓存求解状态；edit 成功要求活动草图完成 CalculateStatus 后得到 UnderConstrained 或 WellConstrained。不能把 prepare 的 NotEvaluated/DOF0 当成求解通过或已完全约束。

## 系统边界与风险

仅同一独立毫米零件和显式草图对象，不扩展 WAVE、装配或任意下游实体功能。尺寸恢复为 Driving 可能导致过约束；不得为成功而删除其它约束或表达式，必须失败并恢复。NX getter 可能置 dirty，必须记录真实读取效果，不能读后保存来伪造 clean。验收容差是软件 CAD 比较阈值，不代表制造精度或其它 NX 版本保证。

最终原生17/17、软件31/31、installed MCP13/13通过。

GUI求解时临时设 `Session.Preferences.Sketch.FindMovableObjects=true`，finally恢复原值并回读，不保存用户配置；恢复欠证则UNKNOWN停写。

选中H/V尺寸必须已有AssociatedExpression；原生直接CreateAsReference而无表达式的尺寸属于明确拒绝范围。独立直接夹具为空实体，helpers和非空实体测量不声称额外独立验证；F11未重新做CPROJ源修改传播实验。验收结果仅对应记录的NX2506和参数组合。

最后MCP安全交回已确认。正常退出完成在中断前未确认，随后用户关闭电脑；恢复时无NX/helper。
