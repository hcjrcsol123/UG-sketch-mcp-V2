# F15 独立实体布尔

## 接口

`nx_prepare_boolean` 在当前工作零件中准备独立 NX 原生布尔计划；后续调用现有 `nx_execute_plan`、`nx_get_operation` 和显式 fresh `nx_verify_part`。

| 字段 | 语义 |
| --- | --- |
| `operation_id` | 当前准备请求的唯一操作 ID，沿用现有操作协议 |
| `ownership_id` / `binding_epoch` | 当前接管返回的所有权与代次 |
| `revision_id` | 当前查询得到的修订 |
| `operation` | `unite`、`subtract` 或 `intersect` |
| `target_body_id` | 显式目标实体，必须属于当前工作零件 |
| `tool_body_ids` | 1—32 个唯一工具实体，不能包含目标；使用当前查询标识 |
| `retain_tools` | 必须显式传布尔值；保留或消费工具 |

以上八项均必填。所有输入实体必须为 solid，不提供片体布尔、装配、WAVE 或 Teamcenter。对象标识在修改后应重新查询，不假设 JID/Tag 跨修订或重新加载持久。

返回真实 `feature_id`、完整 `body_ids/bodies` 及 `native_definition`、`result_geometry`；多输出时单值 `body_id` 为 null，调用方必须读取数组。采用 NX 原生集合语义：令目标为 T、所有工具并集为 U，unite 为 T∪U，subtract 为 T\U，intersect 为 T∩U。尤其多工具 intersect 并非目标与每个工具的共同交集。

目标必须产生可确认的实际体积变化且结果非空；无变化或零输出拒绝并验证 Undo 恢复。体积变化门槛为 `max(1e-7, max(abs(V_before), abs(V_result))*1e-9)` mm³：unite 增量须超过该门槛，subtract/intersect 减量须超过该门槛，输出总体积必须大于零。这是数字模型测量判据，不是建模或制造精度。

## 正确性边界

prepare 只读，execute 复用主线程事务、Undo 和停写机制。目标、所有工具、全部结果以及非参与实体均纳入检查；保留工具须保持，消费工具须实际消失，结果数量与全局实体变化须相容。fresh 必须重新回读原生定义及完整几何，保存副本须真实重开核对。

UNKNOWN 不重放、不自动解冻；同 operation_id 只查询已有结果。仅本机 NX2506 有效许可环境；数字模型门限不构成制造精度或其它 NX 版本认证。

### 已记录的保守限制

不能证明既有原生定义、辅助对象、非参与体或保留工具完整保全的操作拒绝并回滚。实测把先前 intersect 的结果作为后续 subtract 工具时发生安全回滚：实际体积变化、数量及普通模型保全均通过，聚合检查 `existing_definitions_preserved` 未通过。该字段合并旧孔/Boolean 定义、辅助对象和曲线检查，当前证据不能进一步断言具体失败子项；不宣称支持任意链式布尔重写。

已有 Boolean 的稳定定义包括输出 ID；后续操作引起历史输出 ID/数量演化可能保守拒绝。多工具上限 32 是输入约束，实测代表使用两个工具，不等于穷举 1—32 个工具或任意复杂曲面。

未对已有 Hole/Revolve 的非空混合夹具进行单独覆盖。
