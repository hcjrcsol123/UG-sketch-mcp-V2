

## 目标和边界

从指定草图的整个有效截面，围绕世界坐标轴线按指定有符号角度创建 NX 原生实体或片体，并支持显式目标的实体 unite/subtract。验证对象包括输入截面域、轴与角度、布尔目标、生成体、事务回滚、重新打开后的特征关系，以及同一实体上重复面 JournalIdentifier 的安全选择。

验收只覆盖已记录的 NX2506、毫米制配置和确定性夹具。单轮通过不证明可靠性、制造精度、其它 NX 版本或所有几何边界。F12 全量矩阵不重跑；只检查本次直接共用或变更的接口路径。

主流程为 `nx_prepare_revolve` → `nx_execute_plan` → 显式 `nx_verify_part`；`nx_get_operation` 只查询操作记录。准备阶段只读，计划种类为 `create_revolve`，桥接命令为 `operation.prepare_revolve`。完整字段、条件必填关系和失败处理见 [API 核对](F13-api-notes.md)。

| 字段 | 约定 |
| --- | --- |
| `sketch_id` | 当前绑定零件中的显式草图；截面包含整张草图的所有有效非 reference 曲线。 |
| `axis_point_mm` | 世界坐标轴线上一点，恰含 3 个有限数，坐标绝对值不超过 1,000,000 mm。 |
| `axis_direction` | 世界坐标系中的 3 个有限分量，向量非零；规范化后遵循右手方向。 |
| `start_angle_deg`, `end_angle_deg` | 有符号角端点，各在 [-360°, 360°]；跨度绝对值大于 1e-9° 且不超过 360°。 |
| `mode` | `create`、`unite`、`subtract`。布尔模式必须显式指定一个当前 solid `target_body_id`；create 不允许目标。 |
| `profile_output` | 默认 `solid`；`sheet` 仅允许与 `create` 同用。 |

轴线必须与草图平面共面，离面轴在准备阶段拒绝。负跨度通过反转原生轴方向并对两个端点取负，保留等价的有向几何；不得仅把跨度改成绝对值。布尔目标必须解析到单个实体。执行结果返回所有输出 `body_ids`/`bodies`。

截面实现支持代码可识别的有效 Line、Arc、Ellipse、Spline 曲线类型，并拒绝 reference 曲线；F13 原生验收实际覆盖 Line、圆形 Arc 和 Ellipse。solid 要求有效闭合的整草图区域；sheet 是显式开放截面路径，须由 NX builder 接受。

面查询保留重复的 `face_ids`，按 JID 后 Tag 排序，并提供一一对应的 `face_refs`；查询结果新增当前 `face_tag`。草图或 Datum 可在支持的面支撑形式中提供 `support_face_tag`，并且必须同时提供 `support_face_id`。Tag 仅在当前会话/修订有效，不是跨 SaveCopy/reopen 身份。唯一 JID 的旧调用可省略 Tag；同体同 JID 多面省略 Tag 会因歧义拒绝。SaveCopy 对歧义或未知面关联在写入前拒绝；若问题仅在 reopen 时发现，则返回 `SAVED` 与 `associationMismatch`，并保留实际保存路径。含重复 Face JID 的模型中，对来源无法识别的固定/未知 Datum 采取保守拒绝；已证实的 `WORLD_FRAME` 与 `two_lines` 非面关联不因此误拒。

## 事务、安全与验证边界

无法证明恢复时必须维持 UNKNOWN 停写。

native 数值容差是 CAD 软件验收限，不代表仪器不确定度或制造公差。一般检查使用已锁定的轴、边界、面积与体积限。椭圆特例仍采用原始 `max(1e-5 mm³, 1e-8 relative)` 解析体积门槛及严格适用条件；没有放宽限值，也没有声称 NX mass-property 精度提高。MCP 通用 inspect 的 `0.99` 与 F13 execute/fresh 的 `0.999999` 是近似读取设置，不构成体积精度承诺；椭圆例外不能推广到其它曲面。

R28 后，r21 在**fresh Verify 中受影响 F13 body 的**下列记录路径加入 declared machine-roundoff 判据，并已通过当前 r21 分层复验：`faces[*].uv_limits` 标量对 `a,b` 要求 `|a-b| ≤ 64·2⁻⁵²·max(1,|a|,|b|)`；`surface_samples[*].uv` 使用同一标量限；对应 `point_mm` 三维点用欧氏距离 `||p-q||₂ ≤ min(64·2⁻⁵²·S, 1e-7 mm)`，`S=max(1,两端六个坐标的最大绝对值)`；`normal` 分量逐项差不超过 `64·2⁻⁵²`，且两端必须通过单位法向检查、夹角 `atan2(||n₁×n₂||, n₁·n₂) ≤ 1e-12 rad`。原始浮点值始终留存，比较器不覆盖证据。该结果仍受限定夹具和字段路径约束。

该例外不扩展到其它路径：Tag、拓扑、shape/数组形状、bbox、radius、axis、edge、NURBS 和所有其它数值仍精确相等；非目标实体、preflight、execute/Undo、共享 F12 比较路径均保持原门禁。派生数值溢出或 normal/unit 检查失败时应安全拒绝，诊断 metric 置 `null` 并标 `finite=false`，保留原始有限 token，不让错误证据序列化失败。原始 diagnostic 两端实际 UTF-8 预算合计限制为 512 KiB。
