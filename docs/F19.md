# F19 特征镜像

## 接口与支持边界

`nx_prepare_feature_mirror` 接受共同字段 `operation_id`、`ownership_id`、`binding_epoch`、`revision_id` 和 `seed_feature_id`，再严格二选一：

| 平面 | 参数 |
| --- | --- |
| 显式平面 | `plane_origin_mm` 和 `plane_normal`，各含三个有限数字；法向长度与 1 的差绝对值不超过 `1e-9`，不会自动归一化 |
| 已有基准面 | `datum_plane_id`，为当前工作部件的原生 `DatumPlaneFeature` JournalIdentifier |

混用、半组或额外字段拒绝；平面可以偏置或倾斜，不局限于世界坐标轴。单位为 mm；变换按 `p' = p - 2 n ((p-o)·n)` 计算。后续使用既有 prepare/execute/operation.get/fresh/Undo/SaveCopy 生命周期和权限控制。

保守支持域为一个完整、轴对齐 box 实体的原生 Create 模式 `BLOCK` 或 `EXTRUDE` 种子，种子不得有下游修改；镜像体与原体及其他现有体的轴对齐包围盒间隙须大于 `1e-6 mm`，反射后顶点坐标绝对值不超过 `1e8 mm`。该 AABB 检查可能拒绝实际不相交的几何。复杂特征、相交或接触、非 box 实体、跨部件引用及其他 NX 版本不在已验证范围；支持代码不等同于全部种类均已实测。已测建模种子为 EXTRUDE，不能把 BLOCK API 存在推作 BLOCK 产品验收。

## 原生关联与保全

产品创建 NX 原生 `MirrorFeature`（`MIRROR_SET`），读回所选种子、数值平面或同部件 datum、原生父特征、唯一镜像实体和与其共体的输出 feature。输出 feature 不是已观察到的容器子项：探针中其 `ContainerFeature` 为 null。每个成功结果核对8顶点、12直边、6裁剪平面、双向边面邻接、外法向、面积、体积、实体一致性及相应反射位置，并重新检查先前对象与已有受支持的原生特征定义。

NX 可能将种子 EXTRUDE 的表达式共享给镜像输出 EXTRUDE：已观察到 owner 从 seed 变 null，users 从 `{seed}` 变为 `{seed, output}`，RHS 添加 ` // Used By ...`。实现只允许已核验的 seed/output 对同一表达式、精确后缀、原值/单位等未变的这类转换，记录原始前后数据；不称表达式所有权未变化。其他表达式仍严格保全。

镜像输出体的同一面面积在重复读取时允许有限非负值至多相差8 ULP。经完整几何与关联验证的镜像输出体，其同面同索引 UV 标量差至多 `64*2^-52*max(1,|a|,|b|)`；采样点欧氏差至多 `min(1e-7 mm,64*2^-52*S)`，`S` 为固定 box、平面原点及采样点坐标量级且至少为1。两次各自核验有限有序5×5网格、平面及仿射残差、法向、切向、叉积方向和非退化性；镜像定义、身份、拓扑、法向、导数及其他原生字段仍严格比较。非镜像旧体不适用上述例外。

原生 builder 读取在专用内层 Undo 中物化并核对库存和 dirty 状态；若清理或恢复不能证明，操作进入 UNKNOWN，禁止重放和自动解冻。真实提交失败的外层 Undo 须重新核对模型，不能仅以异常消失推断恢复。
