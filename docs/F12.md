
# F12：任意有效轮廓拉伸

## 目标与接口决策

扩展现有 `nx_prepare_extrude` → execute → verify 生命周期，移除单圆／轴对齐矩形白名单。仅本机 NX2506、独立毫米零件、当前查询得到的显式 sketch_id。整草图中所有非 reference 的受支持曲线构成 Section；不静默选第一个闭环，不包含参考构造线，不增加区域种子选择接口。

| 要求 | 验收依据 |
| --- | --- |
| F12-R01 有效 Section | Line、Arc、Ellipse、Spline 的闭合多曲线轮廓、凹区、内环及多个独立区域；拒绝退化、重合、自交、分支、开放实体轮廓。精确回读 Section 几何域，而非仅检查曲线数或源草图 parent。 |
| F12-R02 范围与方向 | positive／negative 沿草图实际法向；有限范围支持 legacy depth_mm 或成对 start_offset_mm/end_offset_mm（互斥，end > start，允许有符号距离）。回读原生方向、起止和实际结果位置。 |
| F12-R03 输出与布尔 | profile_output=solid（默认）或 sheet；sheet 仅 create/finite。create 可有多个独立输出体；unite/subtract 使用显式单一 solid target，不影响其它既有体。subtract 分裂结果须被完整回读。 |
| F12-R04 贯穿 | through_all 仅用于显式目标的 solid 布尔；start_offset_mm 默认 0，可显式给定，禁止 depth/end。使用原生 ThroughAll，不以任意大有限距离冒充。 |
| F12-R05 保全与恢复 | 执行前后核对源草图、参考状态、约束、表达式、非目标实体、历史与依赖；实际 Commit 后故障必须由产品 Undo 恢复，不能证明恢复则 UNKNOWN 停写，不重放／自动解冻。 |
| F12-R06 生命周期与持久化 | 定向软件校验请求、旧计划失效、同 ID 查询／幂等、UNKNOWN；原生与安装 MCP 各自实际执行，并保存重开核对。 |
| F12-R07 交接 | 更新源码／构建／本机安装、真实证据、限制、当前现场与后续入口；完成 F12 后停止。 |

有限区间的 start/end 均为沿选定 direction 的毫米坐标，legacy depth 等于 [0, depth]。不自动把开放轮廓转实体；sheet 只有在原生探针与产品验收证实后才标为可用。

## 调用方式与返回值

沿用 `nx_prepare_extrude`、`nx_execute_plan`、`nx_get_operation`、`nx_verify_part`。每步使用显式 operation_id，所有权／binding_epoch／revision_id 与原有生命周期一致；UNKNOWN 只查询原 ID，不重放执行，不自动解冻。先通过当前查询取得 sketch_id 和布尔目标 body_id，编辑后重新查询，不跨编辑假设 JID 不变。

以下是 `nx_prepare_extrude` 的建模字段（另须提供当前所有权／修订与本次 operation_id）：

```json
{
  "sketch_id": "当前查询返回的草图ID",
  "mode": "create",
  "direction": "negative",
  "extent": "finite",
  "profile_output": "solid",
  "start_offset_mm": -2,
  "end_offset_mm": 8
}
```

上述区间沿负法向坐标 [-2,8]，实际从正法向2mm处扫到负法向8mm处，总跨度10mm。兼容旧请求时用单一 `depth_mm>0` 替代起止字段，等价 [0,depth]；不能同时提供 depth 与任一 offset。ThroughAll 仅用于显式 `target_body_id` 的 solid unite/subtract，可给 start_offset_mm，禁止 end/depth。Sheet 请求必须 create/finite，开放或闭合有效曲线均生成侧面片体，不承诺封口实体。

执行返回 `feature_id`、完整 `body_ids`／`bodies` 和当前 `body_inventory`；`body_id` 只作旧接口兼容的首项，不能据此漏掉其它区域或分裂输出。finite 返回实际起止／span，solid 返回总 volume_mm3，sheet 返回 surface_area_mm2／expected_surface_area_mm2；片体 volume 为空。`profile_analysis`／`section_evidence`／`extrude_definition` 和验证 checks 保留实际 Section、原生模式、有效参数与事务后验。部分字段是诊断证据，不代表其它 NX 版本支持。

质量属性精度有接口边界：一般 `nx_inspect_part` 沿用旧 accuracy=0.99；F12 execute 和本次 `nx_verify_part` 的原生 evidence.bodies 使用0.999999。需要按F12记录容差核对体积时，用对应 execute_operation_id／plan_id／feature_id 和当前唯一body_id核对后的 fresh verify evidence，保留inspect旧精度读数为诊断，不能把两者混同。片体面积按裁剪面逐面测量，NewMassProperties.Area在本机片体上不是可靠面积oracle。原生独立NXOpen／UF验证与安装MCP测量加独立解析oracle是不同证据层。

## 支持范围与保守拒绝

仅同一独立毫米零件的原生 Line／Arc（含整圆）／Ellipse／Spline，按当前实际原生定义检查连通、求交、重合与完整有效域。原生内核不能创建或后验不能证明的输入会拒绝／真实回滚，不能把“任意有效轮廓”理解为所有尺度、病态曲率和所有有理样条表达都已穷举。短段／端点等几何判断使用记录的 CAD 容差，接近容差边界时可保守拒绝。

整草图所有非reference曲线参加 Section，没有隐式选第一区域或子集。与活动输出几何重合的reference曲线目前可触发保守拒绝；不把它宣称为任意reference构造都无影响。实体贯穿并不提供无目标的无限create，布尔目标完全消失／无效果等不满足明确结果检查时拒绝或恢复；目标分裂允许多个输出。WAVE／Teamcenter／装配、斜向投影和后续F13—F22功能不在此接口中。

ThroughAll 直接使用 NX 原生限界。若内核因其它体／片体的限界贡献而引入源草图和显式目标归属之外、当前无法独立证明的 parent，产品会拒绝并验证 Undo；当前没有放行这类额外依赖。正向验收将目标和切割截面整体移到路径独立、目标占该方向最终极值的位置，仍在同一零件保全其他对象，核对正负方向及起点确实进入目标后的实际7mm切割。原重叠片体场景的真实拒绝／恢复报告保留，不能将其冒称为成功贯穿。

## 风险与验证方法

主要风险为 Section 漏选内环／独立区域、参考曲线混入、布尔后输出多体、起止符号、片体零体积被误判，以及旧单体后验遗漏。数值证据须同时包括 Section、特征关联、方向／范围和结果几何，不能只凭总体积。容差属于本机 CAD 数值验证，不是制造精度或跨 NX 版本保证。
