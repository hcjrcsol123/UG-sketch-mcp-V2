
# F10 API Notes

## Selected NX API

The sketch-specific API is `NXOpen.SketchCollection.CreateProjectBuilder(Feature operation)` and `NXOpen.SketchProjectBuilder`. Create a new operation with a null feature after activating the target sketch. The builder exposes `Associativity`, `CurveType`, `ProjectAsDumbFixedCurves`, `Tolerance`, `Section`, and `CommitOperation()`. It does not expose a custom projection vector. F10 therefore requires `direction_xyz` to be parallel or antiparallel to the target sketch normal and rejects other vectors during prepare.

Same-part source objects are added to the builder `Section`: use `ScRuleFactory.CreateRuleCurveDumb(Curve[])` for a model curve and `CreateRuleEdgeDumb(Edge[])` for a solid edge. The API documents `Section.AddToSection` seed as a curve, edge, or face. Cross-part source lists are outside F10. The native builder is set explicitly to `CurveType.Original`, `ProjectAsDumbFixedCurves=false`, the requested associativity, and a 0.001 mm builder and section distance/chaining tolerance. The section angle tolerance is set to the NX API value 0.5; no unit conversion is claimed for that API value.

For associative projections, `CommitOperation()` returns the embedded `ProjectCurve` feature (`CPROJ`); the selected sketch geometry is also read back from the target sketch geometry Tag delta. To verify the persistent source list, recreate a `SketchProjectBuilder` for that `ProjectCurve`, read `Associativity`, then read `Section.GetSectionData()` and each `SectionData.GetSectionElementsData()` element through `SectionElementData.GetSectionElementData1()`. Compare the returned section element Tags with the requested source curve or edge Tags. The NX2506 relation probe confirmed that this returns the original source Line Tag. `Section.GetOutputCurves()` returns an internal CPROJ helper curve whose 3D geometry matches the source Line, not the curve projected into the target sketch; this Tag may or may not be present in `Part.Curves`. `Feature.GetParents()` omits the standalone curve source, so it cannot replace the section-element Tag check. The probe also observed `UF.Sket.AskReferenceStatus=Active` for associative and non-associative output curves. F10 determines associativity through the CPROJ feature and its source Section, not through the Sketch reference-status flag. Dispose the transient section data and destroy the builder. A false associativity request creates independent sketch geometry and no CPROJ operation feature; its result must state that no persistent source relation exists.

`SketchProjectBuilder` must be created while the selected sketch is active. F10 preparation is read-only and requires no sketch to be active. Execution sets one undo mark, activates the selected sketch, creates and commits the builder, performs any sketch update while that sketch is active, deactivates it, and then calls `Session.UpdateManager.DoUpdate(mark)`. A failed postcondition uses `UndoToMark`; the adapter reports rollback only after it compares the captured model state with the before snapshot.

## F10 request and geometry scope

The MCP request fields are `sketch_id`, `source_curve_ids`, `direction_xyz`, and `associative`, along with the normal operation credentials. `source_curve_ids` accepts 1 through 128 unique IDs from `nx_inspect_part` (`curve_ids` or a body `edge_ids` entry). The server normalizes the finite nonzero world vector before dispatch. The NX adapter accepts only the target sketch normal or its negative.

The intended analytic source scope is model `Line` and circular `Arc` curves plus linear and circular solid `Edge` objects. A circular source is accepted only when its circle plane is parallel to the target sketch plane; otherwise its orthogonal projection can become an ellipse, which is outside this contract. A line whose projected endpoints coincide within 1e-6 mm is rejected during prepare. Ellipse, spline, convergent, foreign, and unsupported edge types are rejected. Projection is into a native sketch in the same Work Part and creates no WAVE link.

The adapter also captures a complete numeric record for every preexisting `Part.Curves` object before a write. It reuses the existing M2 sketch-geometry reader, which supports Line, Arc, Ellipse, Elliptical Arc, and Spline definitions. A global curve whose complete native definition is unavailable is rejected during prepare; its inventory is not waived or represented by length alone. New global curve Tags are accepted only when they are target sketch outputs or an exact internal curve Tag reported by the single new CPROJ Section and its geometry matches the original source curve. The Section's helper output is compared directly with the selected source geometry even when the helper Tag is absent from `Part.Curves`.

The builder tolerance of 0.001 mm is an NX construction input. Verification uses an independent geometry readback at 1e-6 mm for points and lengths, plus 1e-7 rad for curve-axis direction. The tighter readback tolerance does not change the builder's stored input tolerance.
