
# V2 F03：距离基准面

## 输入和方向

长度使用毫米。`distance_mm` 是沿参考对象原生法向的有符号距离；正、负、零均可输入。法向由 NX 对象读取，不能用世界 Z 方向替代倾斜参考面的法向。

```json
{
  "operation_id": "f03-prepare-1",
  "ownership_id": "<current owner>",
  "binding_epoch": 1,
  "revision_id": "<current revision>",
  "support_datum_plane_id": "<native datum feature ID>",
  "distance_mm": -12.5
}
```

以平面面为参考时，把 `support_datum_plane_id` 替换为 `support_face_id`，使用 `nx_query_faces(selector="all_planar")` 返回的 `face_journal_id`。两个参考字段互斥；不要同时传固定空间基准面使用的 `origin_mm`、`normal` 或 `x_axis`。非平面面、失效标识、混合模式和非有限距离应明确拒绝。固定空间基准面的 F02 输入继续有效。

## 原生关联与检查

准备操作只生成计划，不创建 NX 特征。执行创建原生 `DatumPlaneFeature`，独立验证需检查实际距离定义、位置、法向和父对象。距离定义与参考关系必须来自 NX 原生对象；仅保留用户属性或按计算位置生成固定平面不能满足 F03。

在模型检查中读取距离基准面的定义，在保存副本并重开后再次检查。保存重开会更换所有权和绑定凭据，后续调用使用 `nx_save_copy` 的新返回值。距离基准面返回的 `datum_plane_id` 可用于 F01 草图定位。

NX2506 的关联 Distance 平面使用 `Plane.SetExpression` 设置带符号距离，回读 `Plane.Expression` 并按原生单位转换为毫米。`SetOffsetExpression/SetOffsetFlip` 属于另一套数据接口，不能用于此创建路径；维护时仍须核对真实失败与撤销恢复；保留的代表报告见验收基线。
