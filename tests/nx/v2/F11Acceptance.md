# F11 sketch reference-state acceptance plan

The historical native run recorded 17/17 checks. Its direct snapshot had an empty body inventory and did not separately enumerate Point, Axis or Direction helpers; broad helper/body preservation was covered by production postconditions, not an independent populated-body experiment. Current feature boundaries are documented in `docs/F11.md`.

## Objective and boundary

Verify that the production F11 operation changes only explicitly selected, supported objects in an active Sketch between NX `Reference` and `Active` states. Capture the real state before and after the operation, prove that solver behavior and downstream selection match the requested state, and prove that unrelated model data is preserved. Do not infer success from the adapter response alone.

The tests use the finalized production contract and a uniquely created standalone millimetre part. The test harness must never start, restart, close, or terminate NX or modify an existing user model. A designated operator controls the NX session.

Traceability: `docs/V2.md` F11 and the finalized F11 MCP operation contract. F01–F10 are not repeated except checks directly needed to detect F11 regressions.

## Test layers and evidence labels

Keep these counts separate in all reports:

1. **Offline protocol tests**: MCP schema, validation, routing, serialization, and response semantics; no NX process or model.
2. **STA fake lifecycle tests**: queue and operation lifecycle using the existing fake bridge; no NXOpen call. Record thread identity and native-call counters.
3. **Native subsystem acceptance**: production adapter in the root-operated NX2506 session, with direct NXOpen/UF readback.
4. **Installed MCP smoke**: installed build and real MCP stdio endpoint in the root-operated NX session.

An offline or fake pass is not native NX evidence. A native run documents the tested NX/build/configuration only and does not establish reliability or cross-version behavior.

## Configuration, setup, instrumentation, and safety

- Record UTC run/case IDs, NX/NXOpen/adapter/MCP versions, build identity, active part units, model tolerances, active Sketch, operation/plan IDs, and the complete request and response.
- Before each native run, require an idle NX session, no active task environment, and a saved, unmodified prior Work Part. Create a unique standalone millimetre part and bind only that part. Do not open or edit a human model.
- Read the official NX builder property and enum values from the root-owned probe. Record the exact `OutputState` value and verify `SelectAllProjectFeatureCurves=false`; do not test a broad implicit selection as a valid path.
- Record the probed UF state values (`0 = Reference`, `1 = Active`) and dimension values (`0 = Driving`, `1 = Reference`) as raw evidence alongside enum names.
- Native execution requires an active Sketch and no WorkRegion. Record cached `Sketch.GetStatus()` separately from an evaluated `Sketch.CalculateStatus()` plus numeric DOF. The product must explicitly create a `WorkRegionBuilder`, set `Scope=EntireSketch`, commit/read back/destroy it inside the same Undo transaction before conversion and CalculateStatus; the builder's default `SelectedObjects` getter is not evidence of a persistent current WorkRegion. After execution, verify no active Sketch. Acceptance covers captured model state and transaction recovery; it does not claim the inactive UI WorkRegion preference was restored and does not report `UNKNOWN` solely for that preference.
- For the downstream contour check, set `Section.SetAllowRefCrvs(false)` and use the whole-Sketch feature rule. Compare Section outputs to source curves with one-to-one geometric matching; Section returns temporary output copies whose Tags are not the source Tags.
- Capture direct before/after inventories: selected object Tags and types; all curves and Sketch members; constraints; dimensions, expression `Value`/RHS, `AssociatedDimension.ComputedSize`, and seven probed expression flags; reference/active status; feature order; bodies; solver enum and numerical DOF; active Sketch; dirty state; revision; ownership and write gate. Record both counts and stable identity mapping; do not rely on JIDs alone.
- There are no physical measurement instruments. Calibration is not applicable. Any CAD comparison thresholds are identity/state checks, not claims of metrology accuracy. Report actual NX tolerances and state how exact booleans/enums and numeric values are compared.
- On an uncertain native outcome or unproven undo, retain the model/report, mark the outcome `UNKNOWN`, stop writes, and never replay or auto-unfreeze it.

## Result quality and failure handling

For each layer, report `selected / passed / failed / skipped` and test IDs. Do not merge offline, fake, native, and installed counts into one pass rate. Retain raw JSON/JSONL reports and model copies for failures. A failure record includes the smallest fixture, exact request and configuration, selected/unselected Tags and states, expected versus observed result, native-call/commit count, before/after snapshot, solver enum/DOF and Section geometry evidence, error or exception, Undo outcome, reproduction steps, and a retest criterion. Retest the failed case on a fresh unique part and report, then repeat state preservation, solver, actual Undo where applicable, and Save Copy/reopen. Preserve the original failure evidence.

## Pending decisions before implementation

- Final edit result/error fields and STA/fake test seam; the tool names and request fields are frozen in `nx_prepare_sketch_reference_conversion` / `nx_edit_sketch_reference_conversion` with IDs and target state.
- Dimensions in scope are HorizontalDim/VerticalDim linear millimetre constraints only. Other dimensions require explicit `UNSUPPORTED_DIMENSION`; no angle/radius/diameter conversion claim is made. Test the narrowly allowed selected expression sync on Reference→Active where numeric RHS/Value updates to the pre-state `ComputedSize`; preserve all expression identity/association/unit/flags and all other expressions.
- Ellipse/Spline are explicitly unsupported when selected; retain existing unselected examples in the preservation snapshot.
- Probe-correlated production verification for exact selected-object scope, solver effect, Section geometry matching, real product Undo, and Save Copy/reopen.
- Product-supported rollback fault injection seam and Save Copy/reopen mechanism exposed by the finalized acceptance harness.
